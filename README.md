# Packet Tracer Labs

This folder contains Cisco Packet Tracer practice labs focused on IPv6 configuration, IPv6 neighbor discovery, and wireless troubleshooting.

## Included Labs

### Configure IPv6 Addressing

**File:** `Configure IPv6 Addressing.pka`

Practice configuring IPv6 addresses on network devices and verifying IPv6 connectivity.

### IPv6 Neighbor Discovery

**File:** `IPv6 Neighbor Discovery.pka`

Explore how IPv6 devices discover neighboring devices and resolve local-link information using Neighbor Discovery Protocol (NDP).

### Troubleshoot a Wireless Connection

**File:** `7.3.3-packet-tracer-troubleshoot-a-wireless-connection.pksz_en-US_dd917396-08ce-41f4-8090-6deb290c51a2.pksz`

Troubleshoot a wireless network in Packet Tracer by identifying and correcting connectivity problems.

## Requirements

- Cisco Packet Tracer compatible with the lab file versions
- Basic familiarity with routers, switches, IPv6, and wireless networking

## How to Use

1. Open the desired `.pka` or `.pksz` file in Cisco Packet Tracer.
2. Read the activity instructions and inspect the existing topology.
3. Complete the configuration or troubleshooting tasks.
4. Use Packet Tracer verification tools and device commands to test your work.
5. Save a copy of the completed activity separately if you want to preserve the original lab.

## Useful Verification Commands

On Cisco IOS devices, common commands include:

```text
show running-config
show ipv6 interface brief
show ipv6 interface
show ipv6 neighbors
ping <ipv6-address>
```

The exact commands needed depend on the lab activity.
